**信号 1：财新制造业景气回升 + 价格指数 60.8% 的剪刀差 = 利润分配再重构**

财新 9 月制造业 PMI 50.1%（+0.3）重返扩张，主要原材料购进价格指数 60.8%（+4.2）vs 出厂价格 54.0%（+3.6），**剪刀差从 8 月的 7.2pct 扩大到 6.8pct（仍处历史高位）**。这不是单纯"通胀"，而是**上游（铜/铝/化工/油）在赚利润、中游（设备/家电/电芯）在被压缩**。**可投资判断**：① **铜矿股**（紫金 / 洛阳钼业）Q4 业绩兑现确定性高；② **中游制造**（中微 / 北方华创 / 拓荆）短期有"价格传导不畅"风险，但 2027-2028 业绩弹性大；③ **下游品牌**（苹果 / 立讯 / 蓝思）如果能涨价转嫁，护城河更深——这也是**苹果 Q3 中国份额回升 + 18 Pro 砍单**的根本原因：**只有苹果敢不涨价、敢在"中端受压、高端坚挺"里继续做高 ASP**。

**信号 2：OpenAI 9 月 ARR 500 亿美元（-30% vs 预期）+ Meta / 微软砍 Claude 预算 = 大厂 AI "自研替代"加速**

这 3 个数据合起来讲的是——**大厂不再为"通用 API"付溢价，AI 推理成本被压到 0 边际**。Anthropic 收入承压（25% 收入来自这两家），反而利好**英伟达 GPU + 国产 AI 算力芯片**——**大厂用自研模型 + 自购芯片，比买 API 便宜**。**可投资判断**：① **海光信息 / 寒武纪**等国产 AI 算力芯片 2026 业绩兑现路径更清晰；② **英伟达 GB300 / Rubin** 在大厂自研推理芯片时仍受益（训练仍需 GPU）；③ **Cerebras / Groq** 等 ASIC 公司估值已透支，**短期面临客户关系动荡**（Cerebras 因 OpenAI GPT-6.1 Sol 选 NVIDIA 而一周跌 20%）。

**信号 3：9.20 公积金提取 6→9 项（新增装修、物业费）= 中国房地产从"投资品"切到"消费品"的真正拐点**

这不是"救市"，是"激活"——**1.76 亿缴存人每户平均余额 5-8 万，年化可用空间 8 万亿+**。跟 2015 年棚改货币化是同一种工具，但**锚点从"开发商"切到"居民资产负债表"**。**可投资判断**：① **物业 / 装修**板块（绿城服务 / 碧桂园服务 / 索菲亚 / 欧派）Q4-2027 现金流改善确定性高；② **建材 / 家居**（东方雨虹 / 三棵树 / 顾家家居）受益于"老房翻新"需求释放；③ **公积金可买政策性金融债**——**新增的"耐心资本"是国债 + 政策性金融债的买盘**，利好**30 年期国债**。
